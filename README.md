# Stock Portfolio Tracker 📈

A simple Python project developed as part of my CodeAlpha Python Programming Internship.

## 📌 About the Project

The Stock Portfolio Tracker calculates the total investment based on stock prices and quantities entered by the user. Stock prices are stored in a Python dictionary.

## ✨ Features

- Displays available stocks and their prices
- Takes stock names and quantities as input
- Calculates individual stock investments
- Calculates total portfolio investment
- Saves portfolio details in a TXT file

## 🛠️ Technologies Used

- Python
- Dictionaries
- Loops and Conditional Statements
- User Input and Output
- Basic Arithmetic
- File Handling

## 🚀 How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in your code editor.
4. Run `Stock Portfolio Tracker.py`.
5. Enter a stock name from the available list.
6. Enter a positive quantity to calculate the investment.
